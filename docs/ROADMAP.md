# Roadmap

This roadmap separates delivered capabilities from intended work. Items under **Next** are not implemented.

## Completed

- [x] Java 21 and Spring Boot project setup
- [x] Spring AI integration with Anthropic Claude
- [x] Repository tools: `listFiles`, `readFile`, and `searchCode`
- [x] Secure, review-scoped repository access with path traversal protection
- [x] Autonomous model tool calling
- [x] Evidence-based prompts and stopping rules
- [x] Structured review responses and findings
- [x] Severity and confidence classification
- [x] JSON extraction before output conversion
- [x] Tool execution logging
- [x] Postman-based manual testing

## Next

- [ ] Review activity/event model
- [ ] SSE streaming
- [ ] React + Vite UI
- [ ] Review orchestration improvements
- [ ] Finding validation
- [ ] Prompt and cost optimization
- [ ] MCP exploration
- [ ] Git diff and pull-request review

These items do not imply current GitHub integration, multi-agent review, RAG, or durable persistence. Any such capability should be documented only after it is implemented and verified.
